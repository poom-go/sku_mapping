등록 전 필수 확인 사항

SKU 등록 전 아래 내용을 반드시 확인해주세요.

  • 모든 SKU는 스마트스토어 판매자센터를 통해 등록되어야 합니다.
    ㄴ 쇼핑백, 사은품, 부자재 등 출고에 적용되는 모든 SKU가 포함됩니다.
  • 모든 SKU는 [상품]으로 등록되어야 합니다.
  • 상품 조회/수정에서 일괄 등록은 진행하지 않도록 유의 부탁드립니다.
    ㄴ 동일한 SKU가 출고되는 상품번호를 여러 개로 운영 중인 경우, 미입력된 SKU 목록만 증가하게 됩니다.
    ㄴ 스마트스토어 내 SKU 정보는 삭제가 불가하므로 반드시 본 가이드 기준으로 등록 부탁드립니다.
  • 실물 바코드와 동일한 바코드로 등록되어야 합니다.
    ㄴ 바코드 오등록 시 수정이 불가하므로 정확하게 등록해주세요.

SKU명 입력 기준

1. 스마트스토어 상품명이 아닌 실제 출고되는 상품명으로 입력해주세요.
(잘못된 예시) poomgo 경량 피크닉매트 야외 방수 휴대용 한강 돗자리 핑크 중형
(올바른 예시) 경량 피크닉매트(핑크/중형), 피크닉매트(경량)_핑크/중형
2. 단수 출고 상품(SKU)
입고된 형태 그대로 송장만 부착하여 출고하는 형태입니다.
이 경우 상품(SKU)명 앞에 (송장만부착) 텍스트를 추가하여 등록해주세요.
(잘못된 예시) 양배추즙 100포
(올바른 예시) (송장만부착)양배추즙 100포
3. 옵션 상품(SKU)
1가지 상품에 옵션이 색상, 사이즈, 크기 등으로 나누어 운영되는 경우 각 옵션이 1개의 SKU로 적용됩니다.
SKU 종 수 : 6개

품고 맨투맨 - 사이즈 S - 블랙 / 아이보리
품고 맨투맨 - 사이즈 M - 블랙 / 아이보리
품고 맨투맨 - 사이즈 L - 블랙 / 아이보리

SKU명 입력 시 옵션까지 함께 SKU명에 기입해주세요.

(잘못된 예시) 품고 맨투맨 S 동일한 SKU명으로 등록 / 바코드만 상이한 경우
(올바른 예시) 품고 맨투맨 S 블랙 / 맨투맨 S/블랙

옵션 상품 확인 사항

  • 운영 중인 옵션 상품의 구성 타입이 조합형인지 확인해주세요.
  • 단독형은 풀필먼트 설정이 불가하므로 조합형으로 수정 후 SKU 등록을 진행해주세요.
4. 바코드가 없는 상품(SKU)
실물에 바코드가 없어 출고 시 스캔이 불가한 경우 SKU명 앞에 ★을 기입해주세요.
(잘못된 예시) 비매품_크림5ml
(올바른 예시) ★크림5ml

SKU명 수정 관련 안내

  • 품고 초도입고 전 등록된 SKU명의 수정이 필요한 경우 네이버 물류지원 톡톡으로 문의 후 수정 가능 여부를 안내 받으실 수 있습니다.
  • 단, 바코드 수정은 불가하며 SKU명 / 소비기한 관리 여부 / 로트 관리 여부만 수정 가능합니다.

SKU X 상품 연결하기

해당 과정은 현재 등록하는 상품(SKU)이 출고되어야 하는 상품번호 또는 옵션번호로 연결하는 과정입니다.
예시
상품명 : 품고 맨투맨
상품번호 : 123412341234
옵션 : S/블랙, S/아이보리, M/블랙, M/아이보리
현재 등록하고 있는 SKU가 품고 맨투맨 S/블랙이라고 가정하면,
S/블랙이 출고되어야 하는 상품번호 또는 옵션번호에 매핑해야 재고 연동 및 출고가 가능합니다.
